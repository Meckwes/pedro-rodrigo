# Pedro Rodrigo — Portfólio Sênior

Site portfólio profissional do **Pedro Rodrigo**, Analista Fiscal e Consultor Tributário em Fortaleza/CE.

## Stack

- HTML5 + CSS3 + JavaScript vanilla
- Sem framework, sem build step
- Google Fonts: Playfair Display + Inter + JetBrains Mono
- Imagens: reais + IA (Gemini)

## Estrutura

```
pedro-rodrigo/
├── index.html          # Página única
├── images/             # Fotos e assets
│   ├── pedro-hero.png
│   ├── analise-documentos.png
│   ├── office-workspace.png
│   └── numeros-bg.png
└── README.md
```
